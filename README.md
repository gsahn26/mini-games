# 브라우저 미니 게임

설치 없이 링크만 열면 바로 즐기는 미니 게임 모음입니다.

## 🍄 슈퍼 점프 브로스
👉 https://gsahn26.github.io/mini-games/

슈퍼 마리오풍 사이드 스크롤 플랫포머입니다.

- ←→ / A D: 이동
- 스페이스 / ↑ / W: 점프 (누르는 길이로 점프 높이 조절)
- 적을 밟으면 처치, 옆에서 닿거나 구덩이에 빠지면 목숨 감소
- 코인을 모으고 끝까지 가서 깃발에 도달하면 클리어, 목숨은 3개

## 🗽 NYC 스트라이크
👉 https://gsahn26.github.io/mini-games/nyc-fps.html

어두워진 뉴욕 거리를 배경으로 한 1인칭 슈팅(FPS) 웨이브 소탕전입니다.

- WASD: 이동, Shift: 달리기, Space: 점프
- 마우스: 시점 조작(클릭 시 포인터 고정), 좌클릭: 발사(누르고 있으면 연사), R: 재장전
- 건물과 택시를 엄폐물로 활용하며 적 4웨이브를 모두 처치하면 작전 성공
- 일시정지 화면의 나가기 버튼으로 언제든 메인 화면으로 종료 가능

## ⛏️ 복셀 크래프트
👉 https://gsahn26.github.io/mini-games/voxel-craft.html

마인크래프트풍 블록 샌드박스입니다. 기본은 3인칭 시점이며, 언덕과 나무가 있는 섬을 자유롭게 돌아다니며 블록을 캐고 쌓을 수 있습니다.

- WASD: 이동, 방향키: 시점 조작(대안), Shift: 달리기, Space: 점프, C/Ctrl: 웅크리기(이동 느려짐)
- 마우스: 시점 조작(클릭 시 포인터 고정), V: 1인칭/3인칭 전환
- 좌클릭: 블록 부수기, 우클릭: 블록 설치 (둘 다 누르고 있으면 연속 동작)
- 숫자 1~7 또는 마우스 휠: 하단 단축바에서 블록 종류 선택
- Esc로 일시정지, 일시정지 화면의 나가기 버튼으로 메인 화면 종료 (지은 구조물은 유지됨)
