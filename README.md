# Mini Games

브라우저에서 바로 즐길 수 있는 간단한 미니 게임 모음입니다. 별도 설치 없이 링크만 열면 됩니다.

## 🐍 스네이크 게임
[`index.html`](index.html)

- 방향키 또는 WASD로 이동
- 스페이스바로 일시정지
- 점수 및 로컬 최고 점수 저장

## 🧊 3D 테트리스
[`tetris3d.html`](tetris3d.html)

Three.js로 렌더링한 3D 테트리스입니다.

- ←→: 이동 / ↓: 소프트 드롭 / ↑: 회전 / 스페이스: 하드 드롭
- P: 일시정지
- 마우스 드래그: 카메라 시점 회전, 휠: 줌
- 고스트 블록, 다음 블록 미리보기, 레벨별 가속, 로컬 최고 점수 저장

## 🍄 슈퍼 점프 브로스
[`mario.html`](mario.html)

슈퍼 마리오풍 사이드 스크롤 플랫포머입니다.

- ←→/AD: 이동, 스페이스/↑/W: 점프 (누르는 길이로 점프 높이 조절)
- 적을 밟으면 처치, 옆에서 닿거나 구덩이에 빠지면 목숨 감소
- 코인 수집, 점수, 목숨 3개, 끝까지 가면 깃발로 클리어
